# Change-Calculator

A program to calculate what amount of which coins to use to match given sum.

## Installing

1. Download this repository as a zip.
2. Install Python if needed.

### Usage

1. Run calculator.py with Python.
2. Type in the amount to match.

To customize the coins, run calculator.py with arguments, e.g.: `python calculator.py 1 2 3 5` will use coins valued 1, 2, 3 and 5.
